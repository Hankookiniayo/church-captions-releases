# 교회 실시간 자막 — 설치 파일

설교를 실시간 자막으로 보여 주고, 끝나면 전사문(txt·srt)으로 저장하는 프로그램입니다.
음성 인식은 전부 내 컴퓨터 안에서 돌아갑니다 (소리가 인터넷으로 나가지 않음).

## 받기

오른쪽 **Releases**에서 최신 버전을 받으세요.

**맥** (애플 실리콘 M1~M4, macOS 13 이상): `ChurchCaptions-버전-mac.dmg`

**윈도우** 10/11: `ChurchCaptions-버전-windows-setup.exe` (설치 없이 쓰려면 `windows-portable.zip`)

## 설치

**맥**: dmg를 열고 ChurchCaptions를 Applications 폴더로 끌어다 놓으세요. 처음 열 때 경고가 나오면 시스템 설정 → 개인정보 보호 및 보안 → **그래도 열기**.

**윈도우**: setup.exe를 실행하세요. "Windows의 PC 보호"가 나오면 **추가 정보 → 실행**. 관리자 권한은 필요 없습니다.

## 처음 켤 때

성경 본문 파일(bible.json)을 고르라고 나옵니다. 교회에서 받은 파일을 고르세요. 본문은 저작권 때문에 앱에 들어 있지 않습니다.

음성 인식 모델(약 1.6GB)을 한 번 내려받습니다. 인터넷이 되는 곳에서 미리 한 번 켜 두세요.

## 업데이트

새 버전이 나오면 앱 위쪽에 알림과 [다운로드] 버튼이 뜹니다. 받아서 다시 설치하면 설정과 용어집은 그대로 남습니다.
